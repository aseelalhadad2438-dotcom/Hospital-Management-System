# Hospital-Management-System
Hospital Management System

Project Description

The Hospital Management System is designed to organize and manage patient information, doctor details, appointments, medical records, and bills.

Problem Statement

Manual hospital management can make it difficult to organize patient information, manage appointments, and track payments.

Objectives

- Manage patient and doctor information.
- Schedule and manage appointments.
- Maintain medical records.
- Generate bills and track payment status.

Main Classes

- Patient
- Doctor
- Appointment
- MedicalRecord
- Bill
- Staff

Project Scope

This project focuses on designing a UML Class Diagram for a Hospital Management System.
